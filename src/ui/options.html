    Google sign-in

    How to create the client ID
    1. console.cloud.google.com → create a project → APIs & Services → Library → enable Google Drive API.
    2. Google Auth Platform → Get started: app name, support email, audience External, contact email.
    3. Branding: add a home page and a privacy policy link; then Audience → Publish app (drive.file needs no review).
    4. Clients → Create client → type Web application → add the redirect URI above.
    5. Copy the client ID here and press Save.
